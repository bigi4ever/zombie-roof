# zombie-roof

## מציור לתמונה (`sketch-to-photo/`)

אפליקציה לטלפון: מציירים סקיצה על הלוח, לוחצים "צור תמונה", ובינה מלאכותית הופכת את הציור לתמונה ריאליסטית עם אותם אלמנטים ובאותו סידור.

- פותחים את `sketch-to-photo/` בדפדפן בטלפון (למשל דרך GitHub Pages) ומוסיפים למסך הבית כדי להתקין.
- בפעם הראשונה פותחים את ⚙️ ובוחרים שירות:
  - **Cloudflare (חינם)**: עשרות תמונות ביום. מקימים פעם אחת שרת קטן לפי [ההוראות](sketch-to-photo/CLOUDFLARE.md).
  - **Google Gemini** או **OpenAI**: בתשלום, בערך 4 סנט לתמונה. ב-Gemini צריך להפעיל חיוב ב-AI Studio, כי התוכנית החינמית לא כוללת יצירת תמונות.
- ההגדרות נשמרות רק בטלפון, והציור נשלח רק לשירות שנבחר.
