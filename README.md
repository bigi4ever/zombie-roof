# zombie-roof

## מציור לתמונה (`sketch-to-photo/`)

אפליקציה לטלפון: מציירים סקיצה על הלוח, לוחצים "צור תמונה", ובינה מלאכותית הופכת את הציור לתמונה ריאליסטית עם אותם אלמנטים ובאותו סידור.

- פותחים את `sketch-to-photo/` בדפדפן בטלפון (למשל דרך GitHub Pages) ומוסיפים למסך הבית כדי להתקין.
- בפעם הראשונה פותחים את ⚙️ ומדביקים מפתח API של Google Gemini (חינמי ב-AI Studio) או של OpenAI.
- המפתח נשמר רק בטלפון ונשלח ישירות לשירות שנבחר.
